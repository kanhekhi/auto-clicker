# Auto Clicker 0.1

Auto Clicker para Windows desenvolvido em AutoHotkey, com foco em desempenho, praticidade e controle dos cliques.

### Funcionalidades

* Intervalo de cliques personalizável.
* Variação aleatória de intervalo.
* Suporte a clique esquerdo, direito e duplo clique.
* Atalhos configuráveis pela interface.
* Modo Turbo para maior desempenho.
